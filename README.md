# Calculator
A simple and user-friendly calculator built using HTML, CSS, and JavaScript. The calculator supports basic arithmetic operations with a clean light-theme interface.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Percentage
* 🔢 Decimal number support
* 🧹 AC (Clear) button
* ⌫ Backspace button
* ⌨️ Keyboard support
* ⚠️ Division-by-zero handling
* 📱 Responsive design
* 🎨 Clean light-theme UI

## 🛠️ Technologies Used

* HTML – Structure of the calculator
* CSS – Styling and responsive design
* JavaScript – Calculator functionality and operations
